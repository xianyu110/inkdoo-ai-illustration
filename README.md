## 为什么做 InkDoo

写公众号、博客、技术文章，最磨人的往往不是写，而是配图：

- 图库搜出来的都是西装握手的商务照，和文章内容对不上；
- 通用 AI 画图每张风格都不一样，放在同一篇文章里像拼凑的；
- 最耗时间的其实是「哪段该配图、画什么」，而不是画本身。

InkDoo 把这三件事一起解决：**先读懂全文，再决定每张图放哪、画什么，最后用同一个角色、同一种手绘风格画出来。**

## 功能

- **一键导入文章**：粘贴文章链接自动抓取正文，也可以直接粘贴文本，或上传 `.md` `.txt` `.docx` `.html` 文件（≤ 2 MB，正文 ≤ 12000 字）。
- **智能规划配图**：AI 通读全文，挑出最值得配图的段落，给出每张图的位置和画面描述，你确认后再生成。
- **6 个原创手绘角色**：糯糯（默认）、阿嘟、墨墨、铅头儿、页页、噗噗，每张图生成前都能换。
- **自定义 IP 角色**：上传你自己的吉祥物或品牌形象，之后每篇文章都由它出镜，读者看久了自然记住你。
- **统一画风**：白底、黑色线条加少量点缀色的手绘风格，直接放进公众号、知乎、掘金、CSDN、博客都不违和。
- **后台生成**：提交后可以离开页面，回来在最近作品里查看，失败自动退还额度。
- **中英双语**：界面支持中文和英文。

## 怎么用

1. 打开 [inkdoo.app](https://inkdoo.app/zh)，用 Google 或邮箱登录；
2. 粘贴文章链接、正文，或上传文件；
3. 选择角色和配图张数，点击「规划配图」；
4. 确认规划后逐张生成，下载后直接插进文章。

## FAQ

**Q：哪些平台的链接可以直接导入？**
大多数博客和文章页都可以。如果某个网站拦截了自动抓取，页面会提示，直接复制正文粘贴或上传文件即可。

**Q：需要会写提示词吗？**
不需要。规划和画面描述都由 AI 根据你的文章自动完成，你只需要确认。
